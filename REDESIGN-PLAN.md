## 7. Мобильные версии (после основного прохода)

Правило конвейера: **десктоп-макет — всегда; отдельный мобильный макет — вторым запросом в том же чате ChatGPT** («тепер мобільна версія цієї ж сторінки, 390px» — контекст уже там, почти бесплатно). Для рядовых страниц мобильная версия выводится из десктопной механически (mobile-first Tailwind) и просто проверяется в mobile-viewport — отдельная картинка не нужна.

Экраны, которым нужен ВЫДЕЛЕННЫЙ мобильный макет (структурно другой экран, не «сжатый десктоп»):

- [ ] **Хедер/навигация на мобильном** — бургер, порядок 12 DB-пунктов меню, поиск, CTA «Вступнику»; самое посещаемое место, у абитуриентов мобильный трафик — большинство
- [ ] **Главная (hero) на мобильном** — уже упирались: чипы-факты скрыты на `<sm` из-за фиксированной min-h секции с absolute-слайдами; решить, как показать факты на телефоне (отдельный блок под hero?)
- [ ] **Расписание звонков** — таблица → карточки/лента с подсветкой текущего урока
- [ ] **Документы категории** — длинные названия файлов + метаданные: переизобрести строку списка под узкий экран
- [ ] **Заявка абитуриента `/zayavka`** — конверсионная форма, на телефоне заполняют чаще всего: крупные поля, клавиатурные типы (tel/email), состояния ошибок
- [ ] **Квиз** — прогресс и варианты ответов под палец, результат без горизонтального скролла

Проверка каждого пункта: preview `otfk-alt` в mobile-viewport (375px) + реальные данные из прод-копии БД; следить за тач-мишенями ≥44px и отсутствием горизонтального скролла.
